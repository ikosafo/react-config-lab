All environment variables are read directly from '.env' files into 'appConfig.js' which is then imported

| Variables | Purpose | Files Using it |
| 'React_App_Env' | Current Environment (Development, Staging, Production) appConfig.js ConfigViewer
| 'React_App_Api_Url' | Base Url for Api requests | appConfig.js, ApiService.js |
| 'React_App_App_Name' | Application Display Name | appConfig.js ConfigViewer EnvironmentBanner |
| 'React_App_Log_Level' | Logging level for debugging (Error, Warn, Info) | appConfig.js, Logger.js |
| 'React_App_Enable_Analytics' | Toggle Analytics features (True/False) | appConfig.js, ConfigViewer |

** Reading Methods : ** All Variables are read directly from 'process.env' in [src/config/appConfig.js]

##Task 3 : Environment File Setup

Three environment files have been created

### 1. '.env.local' (personal settings)
** Purpose: ** Your personal local Development

### 2. '.env.production' (team defaults for local work)
** Purpose: ** defaults settings for local development that all team members can use without modification

### 3. '.env.development' (defaults for builds)
** Purpose: ** default settings for development builds (e.g. staging environments)

** Note: ** Both '.env.production' and '.env.development' contains the same default values for local development, ensuring consistency across the team. Developers can override these defaults in their personal '.env.local' file as needed.

### Task 3b : Put the same variable in two different files with different values (example: change API URL).
** 'React_App_Api_Url' is set to 'http://localhost:3000/api' in '.env.local' for development, allowing developers to connect to a local backend server.
** In '.env.production' 'React_App_Api_Url' is set to 'https://api.example.com', which points to the production api endpoint used for staging and production builds
This setup allows developers to easily switch between local and production api endpoints without modifying the code, simply by using the appropriate environment file for their current development or build needs.
